# Winner בחירות 2026

משחק הימורים על תוצאות הבחירות לכנסת (27.10.2026). כל משתתף מחלק 120 מנדטים בין 15 המפלגות, שולח ומשתף בווצאפ. המנהל רואה את כל ההימורים, את ממוצע הקבוצה ואת הדירוג מול תוצאות האמת.

- `index.html` – דף המשתתף (שם → הימור → שליחה → שיתוף). קישור `#v=<שם>~<הימור>` מציג הימור ששותף.
- `admin.html` – דף המנהל (הימורים / ממוצע / תוצאות ודירוג). קורא את ההימורים מגיליון Google שפורסם כ־CSV. הקישור נשמר רק בדפדפן של המנהל.
- `assets/config.js` – מפלגות, גושים, שעת סגירה ופרטי טופס Google.

## הגדרה

1. טופס Google עם שתי שאלות "תשובה קצרה" בסדר הזה: `שם`, `הימור`. בלי איסוף אימיילים ובלי הגבלה לתשובה אחת.
2. קישור עם מילוי מראש → `FORM_ID`, `ENTRY_NAME`, `ENTRY_BET` ב־`assets/config.js`.
3. גיליון התשובות: אזור זמן Jerusalem, ופרסום באינטרנט של "תגובות לטופס 1" כ־CSV. את הקישור מדביקים בדף המנהל.

## כללים

- לכל מפלגה 0 מנדטים או 4 ומעלה, סה״כ בדיוק 120.
- ההימורים ננעלים ב־22:00 שעון ישראל, לפי השעון של השרת (כותרת `Date` של GitHub Pages) ולא לפי שעון המכשיר. הימורים שהגיעו לגיליון אחרי השעה הזו נפסלים בדף המנהל, ו־`tools/close-form.gs` סוגר את הטופס עצמו.
- כל שיתוף בווצאפ שולח תמונה (`assets/cards.js`, ציור על canvas) יחד עם הטקסט, דרך חלון השיתוף של הטלפון. במחשב התמונה יורדת ונפתח ווצאפ עם הטקסט.
- נספר ההימור האחרון של כל שם.
- הניקוד: סכום ההפרשים בכל המפלגות מול התוצאות האמיתיות. נמוך יותר עדיף.

אתר סטטי, בלי שלב בנייה. הרצה מקומית: `python -m http.server 8765`.
